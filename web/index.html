接口契约（前端按此调用，后端需实现） 
POST   /api/user/register          {username, password}                 → 201 {token}
POST   /api/user/login             {username, password}                 → 200 {token}
POST   /api/user/logout            (Authorization)                      → 未实现，前端按本地清除处理
GET    /api/user/profile           (Authorization)                      → 未实现
PATCH  /api/user/updateProfile     (Authorization) {Username, Password}  → 200 {Code, user}
                                     ⚠ 同时更新用户名和密码；用户名变了旧 token 会失效
                                     ⚠ 未排除自身用户名 → 单独改密码会被当成"已占用"

POST   /api/todo/create            (Authorization) {Title, Content}     → 200 {Code, todo}
GET    /api/todo/getTodos          (Authorization)                      → 200 {Code, todos:[...]}
GET    /api/todo/getTodo/:id       (Authorization)                      → 200 {Code, todo}
PATCH  /api/todo/update/:id        (Authorization) {msg, completed}     → 200 {Code, todo}
DELETE /api/todo/delTodo/:id       (Authorization)                      → 200 {Code}

受保护接口读 Authorization 头，值形如 "Bearer <jwt>"。
注意 PATCH 的 {msg, completed} 是整体覆盖：只想改内容时也要把原 completed 传回去。
401 = 未登录/登录失效；404 = 路由不存在（后端没实现）或资源不属于你。
